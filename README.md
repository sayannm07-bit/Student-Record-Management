A menu-driven Python application for storing and managing student records. This is a beginner learning project for the CodeNova Python Programming Internship.

Features :
Add a student with a unique ID
View all saved student records
Search for a student by ID
Update student details
Delete a record after confirmation
Validate age and marks
Store records in a local JSON file

Student Fields : 
Each record stores the student's ID, name, age, course, and marks.

Requirements : 
Python 3
No third-party packages required

Run the Program : 
Open a terminal in this folder and run:
python main.py
On some systems, use python3 main.py.
The program is interactive, so run it in a terminal or app that supports typed input. If your mobile code runner reports EOFError, it may not support interactive input in its current mode.

Data Storage : 
Records are saved to students.json in the program's current working directory. Keep that file if you want to retain your data between runs. Do not use real or sensitive student information in a public repository.

Concepts Practised : 
Functions, loops, dictionaries, input validation, exception handling, JSON, and file handling.
